# Sistema de Apuestas de Futbol

Proyecto desarrollado utilizando principios de Domain-Driven Design (DDD).

## Dominio

El sistema permite gestionar apuestas deportivas sobre partidos de fútbol.

## Procesos implementados

### 1. Registrar apuesta

Permite:
- validar saldo,
- validar estado del partido,
- registrar apuestas.

### 2. Resolver apuesta

Permite:
- verificar resultados,
- calcular ganancias,
- actualizar saldo del usuario.
